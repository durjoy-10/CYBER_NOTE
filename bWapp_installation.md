# bWAPP installation in Kali linux using docker 

## Pull Cmd:    

``` docker pull hackersploit/bwapp-docker```

## Run Cmd:   

```docker run -d -p 80:80 hackersploit/bwapp-docker```

## In Browser:  
 ```http://127.0.0.1/install.php ```
  and click here 

## show all container in docker 
``` docker ps -a  ```
## run a container 
``` docker start container_name or c_id ```

## stop a container 
``` docker stop container_name or c_id ```
## remove a container 
``` docker rm container_name or c_id ```
